# 黑土农情工作流价值调研

> 调研日期：2026-10-23。用途：判断现有四类工作流能否帮助铁岭玉米经营者做出下一步决定，并确定原型期的改进顺序。代码检查依据当前仓库；公开来源按本页列出的入口核对。本文不是田间效果验证，也不代表现有工作流已通过农艺验证。

## 结论

四类工作流的入口和受控执行链路已经成形，但“任务跑完”与“用户获得足够价值”还不是一回事。现阶段系统更擅长说明“哪些数据出现了什么特征”，还不稳定地回答“哪些位置值得跟踪、变化是否持续、下一次观测如何改变判断”。

试点的核心交付应是一段能讲清田况、解释判断并帮助安排下一步的农情解读，地图和操作入口承接其中的空间证据与动作：

1. **观察到了什么**：结论明确区分遥感/天气观测、解释判断和仍未知的农学原因。
2. **在哪里、何时**：用可定位的区域和观测日期，明确它是单期相对差异还是跨期持续变化。
3. **下一步做什么**：明确需要等待新影像、补一个数据源、核看某区域，或在证据不足时停止判断。
4. **后来发生了什么**：新数据到达后对同一关注区域复查，说明持续、减弱、恢复或暂不可观察。

当前可把前三项作为结果语言与地图的交付目标；长势工作流已先使用相邻日期的空间近邻分区形成保守的持续性摘要，但完整的共同有效像元斑块追踪仍需继续校准。现场巡田记录暂缺不应阻止系统工作，但也意味着水氮原因、受灾事实和防护效果不能由遥感单独确证。

## 结果语言的交付标准

结果开头直接回答这块田目前最值得关注什么。正文用连贯段落说明区域、日期和变化的意义，再解释证据如何支持判断；只有实际影响判断的缺口才进入“还需确认”。下一步应对应这次结果，优先选择能减少关键不确定性的动作。简单追问只回答相关部分，不重复整份结果。

`analysis-brief-v2` 已改写四类工作流的确定性底稿，并同步模型文字编辑与对话提示。底稿区分单期差异和跨期趋势、水氮线索与确诊、雷达变化与疑似积水、预报风险与已发生冻害。知识检索继续提供农学解释和出处，不增加当前地块的诊断确定性。现有文字编辑仍受事实保留校验约束；编辑失败时采用底稿，不能把接入模型描述为已验证的自由农学诊断能力。新任务使用新版底稿，已保存任务不自动改写。

语言验收至少检查：第一句能否独立表达主要判断；每项关键数字能否解释其意义并追溯到来源；单期低值是否被误写成持续恶化；原因与行动是否符合实际证据；没有巡田记录时是否仍能解释现有观测；普通追问是否自然回应。自动测试可检查日期、数值、分支与判断边界，中文表达是否专业、有帮助仍需由农技人员和试用者阅读评估。

## 按工作流评估

| 工作流 | 目前能交付的价值 | 当前边界 | 试点应补足的结果 |
| --- | --- | --- | --- |
| 关键生育期长势监测 | Sentinel-2 多日期指数、有效覆盖、播后天数阶段、单期相对分区、总体趋势和关注动作；时间序列足够时可以描述整体变化 | 阶段主要按播后天数估计；“偏弱区”是最新影像的田内相对低值，不等于病因、持续异常或减产。均值下降不一定代表具体区域下降 | 先补共同有效像元上的跨期空间差异；识别持续、扩张、减弱与恢复区域；保留首次/最近观测日期、面积口径和覆盖；区域无法匹配时明确新出现/消失/不可比较 |
| 水氮协同诊断 | 定位相对光谱差异；叠加近期降雨、雷达变化、土壤背景和明确选择的现场记录后，形成水分/氮素候选解释与核查顺序 | 没有现场记录时，缺氮只能是待查原因；雷达和降雨不足以区分所有根区水分、养分、病害与管理差异。SoilGrids 是背景，不能解释田内差异 | 默认使用“水氮相关线索/原因未确认”，展示各候选原因分别得到哪些支持和冲突；现场记录缺失时仍交付异常区域和下一步区分性检查，不命名“缺氮区”，不自动发出处方 |
| 农田积水灾害识别 | 在同轨可比 Sentinel-1 前后观测和关联降雨同时可用时，找出疑似变化区域；DEM 只调整核查排序 | 现算法将栅格结果按固定 3×3 分区聚合。雷达后向散射变化不是积水深度，也可能由作物、耕作及地表湿度变化造成；低分辨率 DEM 不表达田沟、田埂和微地形 | 按共同有效像元生成连通变化斑块，而不是整块九宫格；每个斑块展示前后日期、变化面积、有效覆盖和降雨对应窗口；没有灾前基线或降雨证据时只返回“雷达变化/待核查” |
| 霜冻风险提前预警 | 用最新低温预报、生育期估计和低洼地形背景给出风险窗口和相对关注区 | 预报格点远粗于小地块，阶段受播种日期/品种误差影响；按请求生成一次的结果不是会更新、升级和解除的预警服务；“低洼”不等于实测温差 | 显示预报签发时间、有效起止和距当前时效；新预报到来后重算并对比风险升级/下降/解除；将低洼区仅表达为相对关注背景，不标成田内精确最低温；过期数据进入 expired/数据中断，不显示风险解除 |

## 当前结果的价值等级

**可以直接作为操作入口**：影像日期、数据有效覆盖、播后天数、整体指数变化、可用数据缺口、来源/运行状态、后续数据准备动作。这些是可复查事实或流程状态。

**可以用来排序或提示**：单期相对低值区、DEM 相对低洼区、雷达显著变化区、粗分辨率天气风险。必须描述为相对关注或疑似范围，不能省略空间/时间尺度。

**现阶段不能作为确定结论**：缺氮确诊、灌溉/施肥量、积水深度、霜冻导致的已发生损害、产量损失、增产节水效果。现有代码没有相应田间真值、校准模型或连续对照。

代码中仍需继续校准的是**总体时间趋势与空间行动的严格对齐**：当前长势结果已经对相邻日期的空间近邻分区给出保守的持续性摘要，但总体均值变化仍不能单独证明某个最新偏弱区就是整段时间持续下降的区域；固定网格分区也不等于最终的共同有效像元斑块。完整目标已在[工具体系设计](farm-agent-tool-system-plan.md)提出 `analyze_field_change`，应继续作为单一任务增强，而不是继续堆更多指标或再建一个 Agent。

## 改进顺序

### P0：先让已有结论更可判读

- 每条发现标清“观测事实、分析判断、待核原因、建议动作”，并显示来源与日期。
- 所有分区面积绑定有效像元与该图层日期；图层日期不匹配时不把发现叠加到地图上。
- 长势偏弱、雷达变化、低洼背景分别命名，不合并成“灾害区”或“缺氮区”。
- 对每种主要失败状态说明已完成什么、缺什么、补齐后能否继续。用户应看到任务不完整的原因和最短可行下一步。
- 土壤背景数据失效时不阻塞其他分析、不造零值。当前 SoilGrids 官方页面注明 REST API 服务暂停，须先确认下载端点与缓存数据是否仍可用；不可用则显示“土壤背景缺失”，水氮解释降级。

### P1：把多期变化做成一项真正的决策能力

- 只在共同有效像元和同一地块边界版本上比较日期；处理分辨率、配准和质量差异。
- 由连通组件生成变化区，而不是固定 3×3 九宫格；保留像元数、真实面积、日期和图层哈希。
- 为后续同一地块分析关联关注区。允许区域持续、拆分、合并、新出现和暂不可观察；关联不上的情况不能假称恢复。
- 输出简单状态：`持续`、`扩张`、`减弱/恢复`、`新出现`、`暂不可比较`，每个状态都附对应日期和证据。
- 长势首个真实任务先验收；其他工作流复用同一空间/时间结构，再分别用合格输入验收。

### P2：形成行动闭环，但不把现场记录当作启动门槛

- 现场核查作为可选建议，不要求用户先建立巡田档案才能获得基础分析。
- 对没有现场记录的水氮任务，交付“已定位的异常 + 当前支持/不支持的原因 + 哪种观测最能区分原因”，不伪装诊断完成。
- 对积水任务，明确区分灾前/灾后和后续退水观测；不能只凭一个结果暗示排水已完成。
- 对霜冻，风险预警与灾后损伤评估是不同任务；当前只有前者，灾后不能自动声称受损面积或产量损失。
- 下一期遥感/预报数据到达时发起比较；没有新数据则说明“尚无新的可比观测”，而不是用旧结果冒充当前状况。

## 面向试点的验收口径

首阶段同时检查语言可理解性与任务证据，不能只用回复流畅度或指标数量验收。使用一块经授权、玉米边界已核对的真实地块和一个明确时段，按实际可获取数据完成任务，并逐条记录：

- 数据来源、获取/签发时间、观察时间、有效空间覆盖和质量状态是否显示正确；
- 单期、缺播期、云遮挡、无同轨雷达、缺降雨、土壤源故障和过期预报是否返回对应缺口；
- 任一“异常/变化区”能否从结果回到同一日期的地图像元/斑块；面积是否能从有效像元重算；
- 相对低值、疑似积水、预报风险是否被错误说成确定病因或已发生损害；
- 下一步是否针对当前缺口，而不是通用“请现场核查”；
- 新一轮输入相同时能否重放；新一期影像到达后能否对原区域给出持续/变化/不可比较；
- 农技人员对每项发现的接受、修订或否决及原因。没有独立地面观察时，记录只能评价可用性和证据一致性，不能宣称分类准确率、农艺效果或增产收益。

试点报告至少分开三类通过：工程可重复、农情解释获专业人员认可、实际经营动作有帮助。前一项通过不代表后两项通过。

## 外部证据与来源

- [Copernicus SentiWiki: Sentinel-2 Products](https://sentiwiki.copernicus.eu/web/s2-products)：产品按轨道/数据条带/固定 granule 组织，尺度和观测完整性需在解释多期比较时显式处理。
- [Copernicus SentiWiki: Sentinel-1 Products](https://sentiwiki.copernicus.eu/web/s1-products)：Sentinel-1 是 C 波段 SAR；后向散射受成像与散射机制影响，必须作为观测证据而不是积水深度/作物损伤的直接测量。
- [ISRIC SoilGrids](https://www.isric.org/explore/soilgrids)：全球土壤属性预测栅格分辨率为 250 米，适合区域/地块背景，不适合充当小地块内田间实测。调研当日该站提示 REST API 暂停服务，接入状态需要重新核验。
- [中央气象台农业气象灾害风险预警入口](https://www.nmc.cn/publish/nongyeqixiang/quanguonongyeqixiangzaihaifengxianyujing/index.html)：可作为动态农业气象产品的官方发现入口；每次使用仍须保存具体产品批次、发布时间、有效期和原文/接口快照。页面存在不等于当前有适用于目标地块的预报。
- [辽宁省农业农村厅 2024 年粮油作物生产技术指导文件](https://nync.ln.gov.cn/nync/index/zwgk/zszdgkwj/2024031114442896015/index.shtml)：地方栽培语境参考；原文复用许可需另行核实，不能因公开可访问就复制全文。
- [Mapping of Phenological Traits in Northeast China Maize (2022)](https://doi.org/10.3390/agronomy12102585)：可支撑东北物候背景，但物候空间估算不替代当前地块的实测生育期。
- [Effects of Temperature on Growth and Grain Maturity of Spring Maize in Northeast China (2023)](https://doi.org/10.3390/atmos14121755)：东北春玉米播期与温度研究适合解释热量背景，不是霜冻预报或当前田间损伤阈值。
- [Influence of Soil Properties on Maize and Wheat Nitrogen Status Assessment from Sentinel-2 Data (2020)](https://doi.org/10.3390/rs12142175)：研究显示土壤差异会影响遥感氮状态估计；研究区与铁岭不同，支持“应分开呈现光谱线索和土壤背景”，不支持移植其精度。
- [Inundated Vegetation Mapping Using SAR Data (2022)](https://doi.org/10.3390/rs14246374)：洪水植被 SAR 散射研究可解释积水机制；美国研究区的精度不作为辽宁玉米精度。
- [Effects of Waterlogging at Different Developmental Stages on Forage Maize (2025)](https://doi.org/10.3390/agronomy15102389)：韩国青贮玉米受控试验可支持“涝渍影响依阶段不同”，不能把处理时长/减产率迁移到辽宁籽粒玉米。
- [Chilling Tolerance in Maize (2022)](https://doi.org/10.3390/plants11162082)：综述可解释玉米低温生理响应；冷害和结冰霜冻不同，不能据此设定地块的霜冻风险阈值。

## 交付建议

继续保留一个 Agent、四条工作流和现有知识检索。近期工程投入优先放在**跨期斑块变化、来源/质量显示、任务失败后的下一步**；并行确认 SoilGrids 下载/缓存可用性。暂不扩建通用农业知识门户、自动施肥处方或完整现场管理平台。首个试点目标是一条可重放、可定位、可以解释“现在知道什么/不知道什么/下一步看什么”的真实玉米地块任务。
